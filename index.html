品牌简介

土豆云(POTATO)把订阅、节点与多端配置放在同一条路径上：购买后复制订阅链接，在对应系统的客户端中导入即可更新节点。服务侧重点是线路可用性、流媒体解锁与游戏向专线，而不是堆砌无法核验的宣传数字。

基础线路覆盖日常网页与通讯；旗舰与团队档位增加流量、同时在线设备与 IPLC 游戏优化，并提供更及时的工单通道。无论你使用 Clash 系、Shadowrocket 还是其他兼容订阅的加速器，流程都是「选套餐 → 取订阅 → 选客户端 → 导入连接」。

使用场景

跨境办公与资料协作

远程会议、代码仓库、云盘与海外文档需要持续可用的出口。基础版可覆盖轻量协作；文档与会议并发较高时，旗舰版的设备数与工单优先级更合适。

流媒体与内容站点

观看或检索海外媒体时，关键是节点是否原生解锁而非单纯延迟。旗舰版强调全节点原生流媒体解锁；基础版适合偶尔使用的基础片源。

游戏与实时对战

对延迟抖动敏感的对战或下载，可走 IPLC 专线优化档位。团队版适合工作室多开与定制分流，避免把办公与娱乐流量挤在同一条拥挤线路上。

学习与多设备切换

手机、电脑、平板轮换使用时，先确认套餐设备上限，再在各端用同一订阅导入。不要在超过上限的终端同时常开连接，以免挤占会话。

操作说明

按纵向步骤完成即可，无需在页面内填写表单。任何一步卡住，可先看下方客户端选择与 FAQ。

  1. 确认需求并选择套餐。 对照流量、设备数、流媒体与游戏是否需要 IPLC。个人轻度使用选基础版；多端加流媒体与游戏选旗舰版；多人共用选团队版。
  2. 完成订阅并复制链接。 在账户中找到机场订阅地址，整段复制。订阅是客户端拉节点的唯一凭证，不要发到公开群组。
  3. 进入客户端选择。 按系统挑选兼容订阅的应用（见下一节）。只安装一个主力客户端，避免多个加速器同时接管系统代理。
  4. 导入订阅并更新节点。 在客户端选择「从 URL 导入」或「订阅管理」，粘贴链接后更新。确认出现节点列表再进入下一步。
  5. 选择节点并开启系统代理。 网页浏览可选综合延迟较低的节点；流媒体选标注解锁的入口；游戏优先 IPLC。连接后用浏览器访问目标站点验证。

更换设备时重复第 3–5 步即可。流量以套餐周期重置，不必反复重装客户端。

客户端选择

土豆云(POTATO)通过标准订阅对接常见加速器，不绑定单一闭源安装包。请先认准系统，再选维护活跃、支持订阅导入的客户端，然后回到操作说明完成导入。以下为选择原则，下载请使用各应用的官方发布渠道或系统商店，本页仅用锚点组织指引。

Windows

优先选择可导入 Clash / Sing-Box 订阅、能开关系统代理的图形客户端。导入后检查是否开启「系统代理」或 TUN。不要同时开多个 VPN 工具，以免路由冲突。

macOS

可选 Clash 兼容客户端或 Surge 等规则型加速器。导入订阅后允许网络扩展权限，并在菜单栏确认连接状态。若浏览器仍走直连，检查是否排除了本机回环。

Android

使用支持订阅与分应用代理的 Clash Meta 类应用。按需开启「绕过中国大陆」以降低无关流量消耗。省电策略可能杀掉后台，连接不稳定时可锁定后台运行。

iOS 与 iPadOS

常用 Shadowrocket、Stash 等支持订阅的客户端。从商店安装后粘贴土豆云订阅，更新节点，开启 VPN 配置描述。蜂窝与 Wi-Fi 切换后若中断，重新打开连接即可。

如何判断选对了

客户端应能：粘贴 URL、定时更新节点、手动选节点、开关系统代理。若只能填单个服务器且无法批量更新，说明不是机场订阅客户端，请换用上一列表中的类型。

官方下载指引入口：客户端选择 与 操作说明。遇到导入失败，先核对订阅是否完整、客户端是否最新，再对照 FAQ。

常见问题

土豆云(POTATO)是什么？和普通 VPN 有何不同？

土豆云(POTATO)是机场订阅服务：你得到的是可更新的节点列表，而不是单一固定服务器。通过 Clash、Shadowrocket 等客户端导入后，可按延迟、解锁能力切换线路，更适合同时需要网页、流媒体与游戏加速的用法。

客户端应该去哪里下载？官网是否提供安装包？

客户端请从各系统商店或该开源项目的正式发布页获取，避免来路不明的打包文件。本站作为土豆云(POTATO)官方网站，重点提供订阅说明与客户端选择标准，下载入口以本页锚点「客户端选择」为准，不在正文外链第三方镜像。

基础版、旗舰版、团队版怎么选？

以流量、同时在线设备和能力为准：每月约 100GB、三台设备、基础流媒体选基础版；需要 300GB、五台设备、全节点原生解锁和 IPLC 游戏优化选旗舰版；二十台设备、高带宽与定制路由选团队版。按年付对应为 ¥150、¥350、¥850。

导入订阅后没有节点或无法连接怎么办？

先确认链接完整、客户端已更新订阅、系统时间正确。关闭其他 VPN 或系统代理插件后重试。若仅个别节点失败，换一条同区域线路；若全部失败，按套餐工单通道反馈节点与客户端名称，便于对照日志。

流媒体缓冲或游戏掉线如何处理？

缓冲多与解锁类型有关，旗舰版强调全节点原生解锁，请改用对应入口而非普通中转。游戏掉线优先切 IPLC 优化节点，并避免 Wi-Fi 与蜂窝频繁切换。团队版可按业务做分流，把游戏与下载拆到不同规则。

设备数超限或流量用尽会怎样？

超过同时在线上限时，新设备可能挤掉旧会话，请关掉长期挂机的终端。流量用尽后极速额度不再可用，可等待周期重置或升级档位。团队共用时建议约定设备清单，避免无人值守的下载占满额度。
